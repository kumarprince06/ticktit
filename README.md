# 🎟️ Ticktit - Book Tickets Together
Tickit karo, seat pakdo. Book with your gang, not alone.

Ticktit is a movie ticket booking platform with Group Booking as USP.
BookMyShow is for solo booking. Ticktit is for friends - create group, pick seats together, split payment.

## 📁 Monorepo
ticktit/
├── backend/   - Spring Boot API
├── frontend/  - React Web App
├── app/       - Mobile App (Coming Soon)
├── docs/      - Architecture, API, DB Design
└── docker-compose.yml

## 🚀 How To Run
```bash
docker compose up -d
cd backend
./mvnw spring-boot:run

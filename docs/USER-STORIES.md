# Ticktit - User Stories

- US-01: As a Leader, I want to create a group with a code, so friends can join easily.
- US-02: As a Member, I want to join via link without typing code, so I don't waste time.
- US-03: As a Member, I want to see live seat map, so I know which seats are taken.
- US-04: As a Leader, I want to lock seats for 5 min, so no one else takes them while we pay.
- US-05: As a Member, I want to pay only my share via UPI, so I don't depend on leader.
- US-06: As a Member, I want to get QR ticket on SMS/Email, so I can enter theatre.
- US-07: As a Leader, I want to see who has paid / not paid, so I can remind them.
